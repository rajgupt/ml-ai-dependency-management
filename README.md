# Dependency Management for ML & AI Projects — A Practitioner's Cookbook

A self-paced, ≤3-hour course for working data scientists, ML engineers and MLOps
practitioners. Cookbook style: every module ends in a copy-pasteable recipe, and
three hands-on labs take you from an empty directory to a packaged, containerized,
audited ML project.

**Status:** curriculum design. See **[COURSE-PLAN.md](COURSE-PLAN.md)** for the
module map, timings, lab briefs, reading list, and the GitBook + PDF build plan.
